# Theory of Mind

Социальный контур (S5): модель партнёра (`partner_trust`, `partner_state`),
сигнатура и узнавание, имена/алиасы, тайминг диалога, Vigilance Gate,
Joint Agency. Спроектировано — см. [`stages/S5_SPEC.md`](../../stages/S5_SPEC.md)
и [`stages/S5_PLAN.md`](../../stages/S5_PLAN.md); код — проход 1/2 S5.

Ключевые принципы (ADR-0008):
- **Идентичность — вывод, не тег:** сигнатура партнёра (эмбеддинг стиля +
  тайминг + предпочтения) → матчинг; отдельного хранилища нет (домен общей
  памяти).
- **Имя — объявленный символ-якорь:** не выводимо, приходит извне, хранится
  поверх сигнатуры.
- **Vigilance:** новые утверждения — гипотезы до подтверждения практикой.

Манифест §3.Г (ToM, Vigilance, Joint Agency); ADR-0008 (атрибуция, узнавание,
имена).
