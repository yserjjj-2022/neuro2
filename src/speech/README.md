# Speech

Речевой актюатор (S3). Превращает состояние хоста в реплику; **не рассуждает**
(ADR-0007: LLM — зона Брока, не центр принятия решений).

Трек (манифест §4, ADR-0003):
- **Б1 (S3, реализовано):** Intent-Frame → облачный LLM API
- Б2: Activation Steering на локальной SLM (Фаза 2+)
- Б3–Б4: CMLA / Emergent Communication (Фаза 3–4)

## Состав

| Файл | Роль |
|---|---|
| `intent.py` | IntentFrame, речевые режимы (register), рендер промпта (Core) |
| `history.py` | `ConversationHistory` — буфер диалога |
| `llm.py` | LLM-клиенты (fake/api) + фабрика (env `LLM_*`) |
| `controller.py` | `should_speak` + `SpeechController` (recall → frame → LLM) |
| `chat.py` | `ChatSession` — CLI-стенд (`/clear`, `/quit`) |

## Запуск

```bash
uv run python -m src --chat --llm auto --db host_memory.db
```

`--llm auto` — реальная модель при наличии ключа, иначе fake.
`--register brief|terse|normal|story` — длина ответа.
`--reasoning` — включить reasoning (по умолчанию выкл).
`--status` — печатать состояние хоста перед каждой репликой.

Ключ: `LLM_API_KEY`, при отсутствии — универсальный `EMBEDDER_API_KEY`.

### Как вести диалог

1. **Запустить** (пример с реальной моделью и индикаторами):

   ```bash
   uv run python -m src --chat --llm auto --status --db host_memory.db
   ```

   Если ключа нет — `--llm fake` даёт детерминированный стенд без сети.

2. **Писать реплики** в приглашение `> `. На каждую реплику loop прокручивает
   несколько тиков (аффективный контур), затем хост отвечает.

3. **Читать индикатор** (при `--status`) — состояние, из которого собран ответ:

   ```
   [F=18.06 val=-16.83 stress=1.36 γ=9.95 задача=tone recall=1 дрейф=нет]
   > привет
   привет.
   ```

   - `F` — свободная энергия (растёт → напряжение);
   - `val` — валентность (знак настроения);
   - `stress` — аллостатический стресс;
   - `γ` — агрегат precision (вес предсказаний);
   - `задача` — активный аттрактор (колонка);
   - `recall` — нашёлся ли прецедент в памяти (`1`/`0`);
   - `дрейф` — сработал ли детектор дрейфа.

4. **Команды:**
   - `/clear` — очистить историю диалога (память эпизодов сохраняется);
   - `/quit` — выйти.

5. **Ручки длины ответа:** `--register terse|brief|normal|story`
   (`brief` по умолчанию — 1–2 фразы, как в живом разговоре).
