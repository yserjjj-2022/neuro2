# Task Attractors

Множественная устойчивая динамика выбора задачи через кратковременную пластичность (STP).

Гистерезис + basin of attraction — аттрактор удерживается несмотря на шум входных сигналов,
переключается только при явном превосходстве конкурента (immediate switch).
Ссылка: Kubota & Aihara (2011).

Сложность: Фаза 2 — O(N) per tick (argmax + runner-up).
