# factorization — разреженный дискретный слой (S6)

Дискретный слой хоста как произведение независимых малых факторов
(`mode` / `partner` / `task`) вместо одной комбинаторной POMDP-матрицы.

## Зачем

Манифест §3.Е: полный POMDP по всем переменным даёт комбинаторный взрыв.
Разреженная факторизация держит малые таблицы на фактор и обновляет их
независимо — дёшево и интерпретируемо. ADR-0005 §3.

## Состав

- `models.py` — `Factor`, `FactorizedState` (Core, frozen, валидация).
- `compute.py` — `posterior`, `marginal`, `update_factor`, `argmax_state`.

## Ключевые принципы

- **Независимость факторов:** обновление одного не трогает другие.
- **Совместное распределение не материализуется** (sparse factorization).
- **NumPy-only:** `pymdp` — опциональное будущее (ADR-0009 §6).

Решения — ADR-0005 §3 / ADR-0009 §6. Спека — `SPEC.md`, стадия —
`stages/S6_SPEC.md`.
