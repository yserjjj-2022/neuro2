# Canonical Microcircuits (CMC)

Канонические колоночные микроконтуры — ядро системы.
Слои: L4 (вход u(t)) → L5/6 (состояние x(t)) → L2/3 (ошибка e(t)).

Архитектура (ADR-0004 — Functional Core / Imperative Shell):
- `column_step()` — чистая функция: состояние передаётся явно, не мутируется
- `projection.py` — `resolve_reads`/`segment_names`: имена сегментов → маска
- `CMCEnsemble` — shell: владеет состояниями колонок, агрегирует per-tick

Фаза 1: простая непрерывная динамика (α-EMA), без матриц весов, без SIMD-батчинга.

**Проекции колонок (ADR-0013):** колонка объявляет `ColumnConfig.reads` — имена
сегментов шины, которые читает; при сборке они разрешаются в бинарную маску
полного входа (`m`). Маска означает «не наблюдается» (нечитаемые координаты не
обновляют `x` и не создают `e`), инвариант `[N, In, State]` сохранён. `reads=None`
→ весь вход (legacy). Фактические reads — `CMCEnsemble.resolved_reads`.
