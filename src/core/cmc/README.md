# Canonical Microcircuits (CMC)

Канонические колоночные микроконтуры — ядро системы.
Слои: L4 (вход u(t)) → L5/6 (состояние x(t)) → L2/3 (ошибка e(t)).

Архитектура (ADR-0004 — Functional Core / Imperative Shell):
- `column_step()` — чистая функция: состояние передаётся явно, не мутируется
- `CMCEnsemble` — shell: владеет состояниями колонок, агрегирует per-tick

Фаза 1: простая непрерывная динамика (α-EMA), без матриц весов, без SIMD-батчинга.
Специализации колонок — теги без проекций (проекции — Фаза 2).
