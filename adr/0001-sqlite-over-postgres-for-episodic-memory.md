# ADR-0001: SQLite для эпизодической памяти

## Date
2025-01-16

## Status
Accepted

## Context
Проект требует системы эпизодической памяти для хоста-собеседника. Нужно хранить:
- Эпизоды диалогов (текст, контекст, правки оператора)
- Прецеденты для поиска по схожести (embedding search)
- Временные метки для конссолидации

Выбор между embedded-базой (SQLite) и клиент-серверной (PostgreSQL).

## Decision
Использовать **SQLite + sqlite-vec** для всех сценариев Фазы 1-3.

### Почему SQLite
- **Embedded-архитектура**: 0.1–0.5 мс задержка, нулевой фоновый процесс
- **Один локальный пользователь**: нет потребности в сетевом доступе
- **Нулевая конфигурация**: нет сервера, нет auth, нет connection pooling
- **Один файл**: легко бэкапится, переносится, версионируется
- **sqlite-vec**: нативная поддержка векторного поиска прямо в SQL

### Почему не PostgreSQL
- **Многопользовательский сценарий** ещё не существует
- **Дополнительная инфраструктура**: нужен сервер, конфиг, мониторинг
- **Задержка**: 5-15 мс на подключение + запрос vs 0.1-0.5 мс embedded
- **Overkill для single-user**: 99% функционала PG не будет использоваться

## Consequences
### Положительные
- Быстрая разработка: ноль настроек инфраструктуры
- Низкая задержка для всех операций памяти
- Простота тестирования: in-memory БД для юнит-тестов
- Персистентность: файл на диске, переживает перезапуск

### Отрицательные
- При переходе на многопользовательский сценарий — потребуется миграция на PG
- Ограничения SQLite по concurrent write (но для single-user неактуально)
- sqlite-vec — относительно новая библиотека, экосистема меньше чем у pgvector

### Миграция
Если в Фазе 4+ появится multi-user сценарий:
1. Перенос схемы из SQLite в PostgreSQL (совместимые типы)
2. Замена sqlite-vec на pgvector
3. Добавление connection pooling
4. Настройка replication

На текущий момент это не требует архитектурных изменений в коде — абстракция репозитория памяти изолирует SQL-специфику.

## Confidence
High. Манифест прямо указывает на это решение (раздел 3.Е). Опыт аналогичных embedded-проектов подтверждает.
