# Phase Gate

## Когда использовать
- Начало новой задачи
- Планирование спринта
- Оценка готовности компонента

## Фазы проекта

### Фаза 1: Reactive MVP
**Ядро:** NumPy ядро x(t), F(t), SQLite память
**Речь:** Intent-Frame
**Готовность:** запоминает правки, меняет тон, буфер работает

### Фаза 2: Sensory Agent
**Ядро:** Циркадное время, MCP, аттракторы задач
**Речь:** Локальная SLM, hooks
**Готовность:** учитывает время, напоминает о задачах, MCP интегрирован

### Фаза 3: Co-Player (ToM)
**Ядро:** CMC Fabric, k-WTA, модель партнёра, Vigilance Gate
**Речь:** EvolvingSteeringMemory, CDS корпус
**Готовность:** подстраховывает, распознаёт манипуляции, k-WTA работает

### Фаза 4: Autonomous Subject
**Ядро:** Ночной сон, эпистемический драйв, gamma_persona -> 0
**Речь:** Продукционная модель, Emergent Communication
**Готовность:** автономная неделями, оптимизирует память, развивает стиль

## Алгоритм проверки
1. Определить текущую фазу
2. Проверить укладывание задачи в фазу
3. Если выход за фазу — пометить RISK
4. Зафиксировать результат
