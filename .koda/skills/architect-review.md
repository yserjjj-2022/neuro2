# Architect Review

## Когда использовать
- Перед реализацией нового модуля
- При ревью чужого кода
- При изменении архитектуры

## Чек-лист

### Экологическая рациональность
- [ ] Не переусложняем решение?
- [ ] Можно решить эвристически вместо полного расчёта?
- [ ] Event-triggered: полный расчёт только при F(t) > threshold?

### Архитектурные принципы
- [ ] Нет централизованного контроллера?
- [ ] Разреженная факторизация вместо единой POMDP?
- [ ] Колонки независимы?
- [ ] O(N) масштабирование вместо O(N²)?

### Модульность
- [ ] Каждый блок в отдельном пакете?
- [ ] Нет циклических импортов?
- [ ] Интерфейсы модулей стабильны?

### Конфигурация
- [ ] Все пороги вынесены в конфиг?
- [ ] Нет хардкода магических чисел?

### Телеметрия
- [ ] Логирование [F | Valence | State] присутствует?
- [ ] Самодиагностика реализована?
